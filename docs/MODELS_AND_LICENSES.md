# Model choices for the first gameplay evaluation

Start a session with the lightweight detector and let the creator review candidates immediately. Offer speech transcription, title suggestions and frame review independently. On the 8 GB class laptop, load one large model at a time and record the measured memory peak. Download models only when the creator selects them. These are proposed product defaults pending evaluation on creator footage.

| Job | Compare first | What would change the choice? |
| --- | --- | --- |
| Speech captions | Multilingual Whisper small on CPU INT8, and large-v3-turbo on CUDA through faster-whisper with word timestamps enabled | Choose by correction time per finished clip, accuracy during mixed game audio and inference time. Measure English and Hindi/English separately. Turbo reduces the decoder from 32 layers to four. [OpenAI model card](https://huggingface.co/openai/whisper-large-v3-turbo) · [faster-whisper usage](https://github.com/SYSTRAN/faster-whisper) |
| Frame review | Compare the same ranked candidates with and without three timestamped frames around each event. The prior project selected Qwen3.5 4B. Record the exact local Ollama digest, projector, frame resolution and context length. | Keep review optional unless it improves the number of distinct usable clips in the first five. Sudden motion alone can be a camera pan. Ask the model to describe visible evidence and let the creator fix the boundaries. [Qwen model card](https://huggingface.co/Qwen/Qwen3.5-4B) · [Ollama build](https://ollama.com/library/qwen3.5:4b) |
| Titles and descriptions | A transcript excerpt or editable template, then Qwen2.5 7B through local Ollama. Gemma 2 9B is a comparison when already installed. | Blind-review factual claims, completeness and edit time. Include an interrupted race with no winner visible. A plausible invented winner should fail. [Qwen package](https://ollama.com/library/qwen2.5:7b) · [Gemma package](https://ollama.com/library/gemma2:9b) |
| Other speech engines | Try Parakeet TDT 0.6B v3 on supported languages and WhisperX forced alignment on clips with measured timing errors. | NVIDIA lists 25 European languages. Hindi needs another path. WhisperX alignment depends on a model suitable for the spoken language. Compare timestamp error against manually marked words before adding a second model download. [NVIDIA card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) · [WhisperX](https://github.com/m-bain/whisperX) |

## Reading the speed evidence

SYSTRAN measured faster-whisper 1.1.0 on 13 minutes of audio. Its large-v2, beam-5 GPU run took 63 seconds at FP16 using 4,525 MB, or 59 seconds at INT8 using 2,926 MB, on an RTX 3070 Ti. The CPU small INT8 run took 102 seconds on eight i7-12700K threads. These results justify testing quantization. They do not predict turbo performance, game speech accuracy or export speed on the RTX 5060 Laptop GPU. [Upstream benchmark and settings](https://github.com/SYSTRAN/faster-whisper#benchmark)

## Ideas to compare on the same recordings

Auto-Editor exposes separate margins on either side of a cut. Try a creator-adjustable lead-in and reaction tail for gameplay. PySceneDetect offers an adaptive detector to reduce false cuts during camera motion. Treat suggested cuts as boundary hints, then measure how often each one removes part of a joke or a reaction. This research adds no code from either project. Auto-Editor identifies its repository as Unlicense and calls out differing binary and app asset terms. PySceneDetect's BSD 3-Clause terms include attribution and non-endorsement conditions. [Auto-Editor](https://github.com/WyattBlue/auto-editor) · [PySceneDetect detectors](https://www.scenedetect.com/docs/latest/api/detectors.html) · [PySceneDetect license](https://github.com/Breakthrough/PySceneDetect/blob/main/LICENSE)
